# CruxPlane for Gemini CLI

Scaffold full-stack web apps, REST APIs, workers, dashboards, and websites with instant live previews (`*.cruxpreview.dev`), isolated cloud MicroVMs (`*.cruxplane.run`), encrypted secrets, and managed PostgreSQL—directly from Gemini CLI.

## Install

```bash
gemini extensions install [https://github.com/](https://github.com/)<YOUR_GITHUB_ORG_OR_USER>/cruxplane-gemini-extension
